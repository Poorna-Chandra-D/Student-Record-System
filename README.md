## ✨ Features

- **Secure Authentication** - Admin login with password protection
- **Comprehensive Dashboard** - Real-time statistics and overview
- **Course Management** - Complete CRUD operations for courses
- **Subject Management** - Organize subjects by course
- **Student Registration** - Easy student enrollment process
- **Record Management** - View, edit, and manage student data
- **Session Management** - Academic year/session tracking
- **Profile Management** - Update admin profile and credentials

## 🚀 Getting Started

### Prerequisites

- PHP 7.4 or higher
- MySQL 5.7 or higher
- Apache/Nginx web server
- Modern web browser

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/Poorna-Chandra-D/Student-Record-System.git
   ```

2. Navigate to the project directory
   ```bash
   cd Student-Record-System
   ```

3. Import the database
   - Create a new MySQL database
   - Import the SQL file provided in the project

4. Configure database connection
   - Update database credentials in the configuration file

5. Start your web server and access the application
